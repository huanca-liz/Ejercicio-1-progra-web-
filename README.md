
## Descripción general

Este proyecto contiene dos aplicaciones web independientes desarrolladas utilizando HTML, CSS y JavaScript. Cada ejercicio funciona en una página diferente y resuelve un problema específico mediante interacción con el usuario.

Las aplicaciones incluidas son:

1. Comparación de temperatura
2. Cálculo de número factorial

---

## Página 1: Mejora de temperatura

### Descripción

Esta aplicación permite comparar dos valores de temperatura ingresados por el usuario y determinar si la temperatura aumentó, disminuyó o se mantuvo igual.

### Funcionamiento

El usuario debe ingresar una temperatura inicial y una temperatura final. Al presionar un botón, el sistema procesa los datos y muestra el resultado correspondiente.

### Ejemplo

Entrada: 20 y 25
Salida: La temperatura aumentó
link : https://huanca-liz.github.io/ejer1-y-ejer2/

---

## Página 2: Número factorial

### Descripción

Esta aplicación calcula el factorial de un número entero positivo ingresado por el usuario.

### Definición

El factorial de un número n es el producto de todos los números enteros positivos desde 1 hasta n.

n! = n × (n − 1) × (n − 2) × ... × 1

### Funcionamiento

El usuario ingresa un número y presiona un botón. El sistema calcula el factorial y muestra el resultado en pantalla.

### Ejemplo

Entrada: 5
Salida: 120
link : https://huanca-liz.github.io/ejercicio2/
